# Mini App

Одна страница без сборки: `index.html`. Открывается внутри Telegram, цвета
берёт из темы мессенджера.

## Где она берёт данные

Функция `soroka-app` в Supabase. Единственное доказательство, что страницу
открыл владелец, — строка `initData`, подписанная ботом; функция проверяет
подпись, её возраст и совпадение id с владельцем из базы. Проверено: без
подписи, с чужим id и с суточной подписью — отказ; с настоящей — данные.

Секретов в самой странице нет, поэтому её можно класть на любой публичный
хостинг.

## Чего не хватает — хостинга

Supabase раздать её не может. Проверено тремя способами:

| Способ | Что отдаёт |
|---|---|
| Storage, публичный бакет | `text/plain` |
| Storage, имя без `.html` | `text/plain` |
| Edge Function с `content-type: text/html` | `text/plain` + `CSP: sandbox` |

Это их защита: раздавать чужой HTML со своего домена значит открыть XSS на весь
проект. Обойти нечем — заголовок переписывается на их стороне.

Нужен любой статический хостинг с HTTPS. Подойдёт что угодно из списка,
страница одна и весит 12 КБ:

- **Yandex Object Storage** — уже используется в WooSport и Sprig, отдельный
  аккаунт заводить не надо;
- **GitHub Pages** — бесплатно, публичный репозиторий с одним файлом;
- **Cloudflare Pages**, **Netlify**, **Vercel** — бесплатный тариф, загрузка
  папки мышью.

После загрузки адрес прописывается в двух местах: `APP_URL` в
`supabase/functions/_shared/panel.ts` и `API` в самом `index.html` (если
страница и функция на разных доменах — там же полный адрес функции).
